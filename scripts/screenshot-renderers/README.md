# FlowSnap Documentation Screenshot Renderers

This directory contains standalone Swift scripts used to generate visual screenshots and user-guide illustrations for FlowSnap's technical documentation and user guides (`docs/user-guides/images/`).

## Usage

Each script can be executed standalone using Swift:

```bash
swift scripts/screenshot-renderers/render_core_layout_screenshots.swift
swift scripts/screenshot-renderers/render_visual_menu_and_modern_settings_screenshots.swift
```

Rendered images are automatically output to their respective directories in `docs/user-guides/images/`.
